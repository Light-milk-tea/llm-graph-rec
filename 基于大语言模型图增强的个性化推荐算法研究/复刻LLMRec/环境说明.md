## Netflix 数据

只从作者公开的网盘目录下载训练会打开的文件：

https://drive.google.com/drive/folders/1BGKm3nO4xzhyi_mpKJWcfxgi3sQ2j_Ec

放到 `复刻LLMRec\LLMRec\data\netflix_valid_item\`。不下海报原图。`augmented_user_init_embedding_final` 和 `augmented_total_embed_dict` 会由 `main.py` 在运行时写出来，不单独下载。

目录名用 `netflix_valid_item`，因为 `main.py` 只在数据集名是这个值时建立 Netflix 的属性字典（year、title、director、country、language）。默认参数 `--dataset netflix` 会去找 `data/netflix`，而且不会建立这张字典。开跑时用：

```powershell
python main.py --dataset netflix_valid_item
```


### val.json 与 test.json

大文件下完后，用 val.json 自己的网盘编号又下载了一次。新文件 69921 字节，MD5 仍是 `6fb5073401bd60d44156e942797102ba`，和已经放在目录里的 val.json、test.json 相同。两个编号没有抄混，作者网盘上的验证集和测试集是同一份内容。
