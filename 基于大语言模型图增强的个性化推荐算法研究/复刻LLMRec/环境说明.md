`torch.cuda.is_available()` 为真，设备是 NVIDIA GeForce RTX 4060 Laptop GPU。试建的 CUDA 张量在 `cuda:0` 上。

作者 `requirements.txt` 锁定 Torch 2.0.1 和 CUDA 11.6，还包含整份 Anaconda 包，没有整文件安装。4060 需要更新的 CUDA 轮子，所以使用上面的最小依赖。版本和作者仓库不一致。

```powershell

```

```powershell
python 复刻LLMRec\_download_netflix.py
```

### val.json 与 test.json

两者 MD5 都是 `6fb5073401bd60d44156e942797102ba`。test.json 的大小和网盘标注的 68 KB 相符。val.json 使用的是页面上该文件自己的 `data-id`，不是把 test 的编号抄错。需要在大文件下完后单独再取一次 val.json。如果仍然相同，再决定是作者文件本身相同，还是网盘返回了同一份内容。
